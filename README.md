# PicoChat (Kotlin Multiplatform)

Private AI chat that runs 100% on your device. Kotlin rewrite of the Flutter app with
Compose Multiplatform (Material 3). Models are GGUF files from Hugging Face run by llama.cpp.
Targets: Android, iOS, Windows, Linux, macOS. No web.

## Layout

```
shared/       Kotlin Multiplatform: UI, data, domain, engine, translations (composeResources)
androidApp/   Android shell: manifest, services (assist, notifications, download), icons
desktopApp/   Compose Desktop shell: Windows / Linux / macOS packaging (jpackage)
iosApp/       SwiftUI shell, project generated by XcodeGen (project.yml)
llama/        Android native library (llama.cpp + JNI) built by CMake / NDK
native/       llama_jni.cpp (shared), desktop/ CMake build, ios/ xcframework script
docs/         PORTING.md = Flutter file -> Kotlin file map and progress
.github/workflows/  build-android|windows|macos|linux|ios, build-all, ci, release
```

LlamaBridge (JNI) lives in `shared/src/jvmCommonMain` and is used by Android and desktop.
iOS will use cinterop (see `native/ios/README.md`): the app starts but has no local engine yet.

## Build

JDK 17+ (CI uses 21).

```
./gradlew :androidApp:assembleDebug                 # Android SDK 36, NDK 29, CMake 3.22.1
cmake -S native/desktop -B native/build -DCMAKE_BUILD_TYPE=Release \
      -DPICO_OUT=$PWD/desktopApp/native-libs/<os>-<arch>   # os-arch: linux-x64, macos-arm64, windows-x64...
cmake --build native/build --config Release
./gradlew :desktopApp:run                           # run the desktop app
./gradlew :desktopApp:packageDeb                    # or packageDmg / packageExe / packageRpm
cd iosApp && xcodegen generate && open iosApp.xcodeproj    # macOS only
./gradlew detekt :shared:desktopTest
```

The Android modules (`androidApp`, `llama`) are only included when `local.properties` has `sdk.dir`
or with `-Ppico.android=true`; desktop and iOS builds need no Android SDK.

Android debug and release share `androidApp/debug.keystore`: same signature everywhere.

## Release

Add a `## vX.Y.Z` section to `CHANGELOG.md`, then push a tag `vX.Y.Z` (or run *Release PicoChat*).
Assets: Android APKs (universal + 3 CPUs), Windows installer + zip (x64, arm64), Linux deb / rpm /
AppImage / zip (x64, arm64), macOS dmg + zip (arm64, x64), unsigned iOS ipa.

## Design

Material 3 Expressive without experimental APIs: own spring specs (`ui/theme/Motion.kt`), shape scale (`Shapes.kt`),
Material You colours through `dynamicColorScheme()` (Android 12+, seed colour elsewhere).

## Languages

`shared/src/commonMain/composeResources/files/strings_{en,fr,es,de}.json`.
Use `tr("key")` or `tr("key", mapOf("name" to x))`.
