# Changelog

Release notes are read by .github/workflows/release.yml: add a `## vX.Y.Z` section before tagging.

## v0.1.0

- Material 3 Expressive look: Material You colours (Android 12+), rounder shapes, spring motion, morphing buttons, collapsing large titles, animated screen changes.
- First-run intro, memory (the AI remembers facts you share), settings in sub pages (appearance, language, chat, memory, Hugging Face, storage, privacy, about), rename chats, tokens per second, code copy button.
- Chat works end to end: local llama.cpp engine (Android, desktop), demo engine elsewhere, Hugging Face search and resumable downloads, conversations saved on disk, settings, 4 languages.
- First Kotlin Multiplatform version (Compose Multiplatform): project skeleton, CI and release workflows for Android, iOS, Windows, Linux and macOS.
