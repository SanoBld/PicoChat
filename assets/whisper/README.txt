Put the Whisper model here to ship it inside the app (no download at run time):
  ggml-tiny.bin  (75 MB)   or   ggml-base.bin  (142 MB)   or   ggml-small.bin
Get it from: https://huggingface.co/ggerganov/whisper.cpp/tree/main
The app copies the file that matches the chosen Whisper model on first use.
Without a file here, the app downloads the model the first time you dictate.
